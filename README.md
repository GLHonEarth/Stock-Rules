# 📈 股票智能技术分析与策略决策系统

根据 `request.md`（PRD）实现。系统通过**免费公开数据接口**获取单只 A 股的历史与实时行情，
内置**四大策略引擎**（传统技术面/马丁/反马丁/定投），自动计算买卖点信号，并在
Streamlit 可视化看板中展示，辅助投资决策。

> ⚠️ **免责声明**：本项目为技术分析演示工具，所有信号与回测结果**不构成任何投资建议**。
> 股市有风险，投资需谨慎。马丁策略等高风险策略仅供学习研究。

## 二、环境要求

- Windows / macOS / Linux 均可
- Python 3.9 及以上（推荐 Anaconda，本项目在 Python 3.10 上开发验证）
- 需要联网（数据来自东方财富、新浪财经、百度股市通、巨潮资讯等公开接口）

## 三、安装与启动（三步）

### 第 1 步：进入项目目录

```bash
cd d:\Code\StockRules
```

### 第 2 步：安装依赖

```bash
pip install -r requirements.txt
```

> 国内网络若安装缓慢，可用清华镜像加速：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 第 3 步：启动系统

```bash
streamlit run app.py
```

启动成功后，终端会显示本地访问地址，浏览器会自动打开
**http://localhost:8501**（若未自动打开，手动复制该地址到浏览器）。

### 🪟 Windows 小白方式（双击即可）

双击项目目录下的 **`startup.bat`**，脚本会自动检查/安装依赖并启动系统，
无需手动敲命令。

## 四、界面使用说明

1. **左侧控制区**
   - **📁 我的股票库**：下拉选择要查看的股票，一键切换；`➕ 添加股票` 输入代码或名称
     （如 `600519`、`000001`、`贵州茅台`）加入股票库；`🗑 删除当前股票` 从库中移除
     并**同时清理该股票的全部本地缓存数据**（二次确认）
   - 切换周期：日K / 周K / 月K / 分时
   - 勾选需要启用的策略（默认全部启用）
   - 设置模拟初始资金（用于持仓模拟计算器）
   - 调整 K 线显示数量

2. **缓存优先机制**：启动或切换股票时，**优先读取本地缓存数据（秒开，离线可用）**，
   过期数据由系统在后台自动刷新；页面顶部会显示"数据来源：本地缓存（更新于 xx）"。
   首次使用某只股票或删除后重新添加时，才会联网完整抓取。

3. **🔄 一键更新股票库数据**（侧边栏按钮）：一次性重新抓取股票库中**全部股票**的
   日K/实时/估值/财务数据，带进度显示，完成后自动刷新，让总览页反映最新信号。

4. **📋 股票库总览**（主区顶部的第二个标签页）：把股票库中所有股票按当前策略信号
   **综合分类**展示——
   - 顶部统计条：看多 N 只 / 观望 N 只 / 看空 N 只 / 警示 N 只
   - 策略状态矩阵表：每只股票在 传统/马丁/反马丁/定投 四个策略下的实时状态
   - 分类卡片区：按「看多 / 观望 / 看空 / 警示 / 数据异常」分组，每只股票显示
     名称、代码、最新价和各策略标签，一眼看清股票池整体强弱
   - 综合信号计分规则：看多+1、看空-1、马丁触发警示-2，总分正→看多、负→看空

2. **顶部实时行情卡**：最新价、涨跌幅、今开/昨收、最高/最低、成交量/额、更新时间

3. **当前策略信号看板**：四大策略的状态卡片（如“传统指标：看多”、“马丁策略：等待加仓”），
   带风险提示折叠区

4. **核心图表区**
   - 主图：K 线 + MA5/10/20/60 + 布林带；**🟢▲ 绿箭头=买点，🔴▼ 红箭头=卖点**，悬停查看原因
   - 鼠标拖拽平移、滚轮缩放
   - 副图：成交量（红涨绿跌）、MACD、KDJ、RSI

5. **持仓模拟计算器**：按所选初始资金回测各策略，展示当前持仓数、成本价、市值、可用资金、
   **总权益**、**累计盈亏额**、**累计收益率**、仓位占比，以及历史累计收益率曲线。
   - **累计口径**：马丁/反马丁以「初始资金」为基准，定投以「累计投入」为基准；
     总权益已包含历次平仓**落袋的利润**，因此与「买卖信号明细」一一对应——
     每笔卖出的结果都会直接体现在总权益和累计收益率上

6. **基本面卡片**：PE(TTM)、PE 一年百分位、PB、净利润增长率、所属行业、上市日期

7. **五档盘口**：实时买卖五档报价

## 五、常见问题（FAQ）

| 问题 | 解决办法 |
|---|---|
| 页面提示“数据加载失败/网络连接” | 数据源为免费公开接口，偶发限流。刷新浏览器页面或稍等片刻（缓存优先，未断网时后台会自动重试）。系统内置 3 次重试 + 多数据源自动降级 |
| 首次加载较慢（几秒~几十秒） | 正常。首次使用某只股票需抓取历史行情、估值、财务等数据，之后全部缓存到本地 `cache/` 目录，启动/切换秒开 |
| 输入股票名称搜不到 | 首次名称搜索需下载全市场股票列表（约 30~40 秒），之后缓存 12 小时。系统已自动兼容全角字符/空格（如"万 科Ａ"→"万科A"）及前导零代码（如"平安银行"→000001）。仍搜不到时可换 6 位代码，或检查名称是否有别名（如"万科A"） |
| 想删除某只股票及数据 | 选中该股票 → 侧边栏「🗑 删除当前股票」→ 确认，即从股票库移除并清空其本地缓存 |
| 股票库文件在哪 | `data/stock_library.json`（可手动编辑备份）；缓存文件在 `cache/` 目录 |
| 分时模式下没有策略信号 | 正常。分时仅展示当日走势，策略信号基于日/周/月 K 线计算 |
| 不同周期/不同显示数量下策略结果不同 | 策略在所选 K 线周期的**完整历史**上回测（指标边界值连续），图表仅影响展示多少根 K 线 |
| 想调整策略参数（加仓倍数、止盈目标等） | 编辑 [core/config.py](core/config.py) 中的 `STRATEGY_PARAMS`，保存后刷新页面即可 |
| 端口 8501 被占用 | 终端执行 `streamlit run app.py --server.port 8502` |

## 八、缓存与股票库说明

- **缓存优先**：启动/切换股票时先读本地缓存（`cache/` 下 CSV+时间戳），秒开；过期数据后台线程自动刷新，
  完成后页面自动更新，无需手动点击
- **股票库**：`data/stock_library.json` 保存你添加的股票与最后查看记录，跨会话保留，下次启动自动恢复
- **删除**：删除股票会同时清除该股票的历史/实时/估值/资料等全部缓存文件
- **测试**：`python test_engine.py`（引擎全链路）、`python test_offline.py`（UI 三大新能力，无需联网）

## 七、技术说明

- **数据源**（全部免费、无需 API Key）：东方财富（历史K线）、新浪财经（实时行情/五档/分时）、
  百度股市通（PE/PB 估值及百分位）、巨潮资讯（行业/上市日期）、新浪财务（净利润增长率）
- **估值百分位**：PE 与自身近一年历史比较，避免依赖不可靠的行业平均数据；
  <50% 视为低估、>80% 视为高估（智能定投与基本面策略使用）
- **马丁策略风控（PRD 3.2）**：强制 `最大加仓次数=5`、`总资金止损线=-10%`，触发后停止交易并在界面红色警示
- **缓存策略**：实时行情 20 秒、日K 20 分钟、周/月K 6 小时、估值 12 小时、公司资料 7 天；
  缓存目录 `cache/` 可随时手动清空
